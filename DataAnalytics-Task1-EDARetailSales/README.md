# Task 1 - EDA Retail Sales

## Overview

This project was completed as part of the Oasis Infobyte Data Analytics Internship.

The project focuses on performing Exploratory Data Analysis (EDA) on a retail sales dataset to identify patterns, trends, and useful business insights.

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- Jupyter Notebook

## Project Objectives

- Clean and prepare the dataset
- Explore the data using statistical analysis
- Identify important patterns and trends
- Create meaningful visualizations
- Generate business insights

## Project Files

- `Task1_Retail_Sales_EDA.ipynb` - Complete analysis notebook
- `README.md` - Project documentation
