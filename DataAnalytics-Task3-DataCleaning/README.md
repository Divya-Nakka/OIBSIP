# Task 3 - Data Cleaning

## Overview

This project was completed as part of the Oasis Infobyte Data Analytics Internship.

The project demonstrates professional data cleaning techniques using a deliberately messy Titanic dataset. The objective is to transform the dataset into a clean, consistent, and analysis-ready dataset.

## Tools and Technologies

- Python
- Pandas
- NumPy
- Google Colab
- Jupyter Notebook

## Data Cleaning Process

The project includes:

- Data quality inspection
- Missing value handling
- Duplicate removal
- Categorical data standardisation
- Data type correction
- Outlier detection and treatment
- Before-and-after data quality comparison
- Final data validation

## Project Files

- `Task3_Data_Cleaning.ipynb` - Complete data cleaning analysis
- `cleaned_titanic.csv` - Final cleaned dataset
- `README.md` - Project documentation
